# Captotal

Web de [captotal.com](https://captotal.com) hecha con [Nuxt 4](https://nuxt.com/docs) y Directus como CMS.

## Setup

```bash
npm install
```

## Desarrollo

Servidor en http://localhost:3000

```bash
npm run dev
```

## Producción

```bash
npm run build
pm2 start ecosystem.config.js
```

Previsualizar la build en local:

```bash
npm run preview
```
